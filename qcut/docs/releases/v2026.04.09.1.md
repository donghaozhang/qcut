# QCut v2026.04.09.1

## Features

- **CLI authentication**: Added `login`, `signup`, and `logout` commands for email/password auth
- **Admin create-user endpoint**: Provision test accounts with session tokens via `POST /api/admin/create-user`
- **API key proxy**: Credit-based proxy routing for users without their own API keys
- **Admin routes**: User lookup, bulk credit grants, and plan upgrades via admin API

## Fixes

- Wire `QCUT_AUTH_TOKEN` to proxy session provider in CLI runner
- Distinguish server errors from invalid credentials in CLI login
