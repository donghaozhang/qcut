# QCut v2026.08.25.1

## 人像美颜：多人支持

- **逐脸参数**：同一素材可为不同的人分别保存美颜、脸型、五官与美体参数，
  按本机运行时的人脸跟踪 id 绑定，遮挡后仍认得同一个人
- **人脸识别**：面板新增「识别」按钮，列出画面中真实存在的人脸（不再是固定的
  「人脸 1–10」），并标注本机运行时同时最多对 5 张人脸生效
- **人脸框**：预览上可直接点选人脸切换编辑对象
- 既有单脸项目完全不受影响：存储结构不变，渲染逐字节一致

## 修复

- 切换人脸目标或应用美颜预设时不再丢失逐脸参数
- 逐脸美妆在与人脸目标撞 id 时不再被丢弃
- 人脸检测失败时不再残留临时帧文件

## 研究探针

- 人脸检测支持在运行时自有 GL 上下文中运行，与独立上下文结果逐字段一致
- 探针在引擎上下文模式下不再于退出时销毁运行时持有的上下文
