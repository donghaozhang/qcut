# QCut v2026.05.14.1

- Containerized CLI agent (`@qcut/agent-worker`) — claims jobs from Supabase, runs them in a docker/Daytona sandbox, streams masked stderr, uploads artifacts.
- Phase 2 interactive browser sandbox — Cloudflare Worker relay (`@qcut/qcut-relay`) bridges a browser WebSocket to an E2B PTY through a Durable Object, with HS256 token verify and a single-attachment guard.
- New `/api/sandbox/spawn` license-server route deducts credits, materializes per-user secrets, doctors the sandbox, then signs the relay token.
- `agent_secrets` / `agent_jobs` / `agent_events` / `agent_artifacts` / `sandbox_sessions` tables with a partial queue index and bigint artifact bytes.
- CLI image bootstrap docs covering local docker, GHCR, and E2B template paths.
