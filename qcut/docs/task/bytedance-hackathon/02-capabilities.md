# Seedance 2.0 — Capabilities, Modes, and Input Limits

All facts here are extracted from the official [Create video generation task](https://docs.byteplus.com/en/docs/ModelArk/1520757) reference (fetched 2026-05-02).

## Real-face restriction (and its workarounds)

> Seedance 2.0 series models do not support direct upload of reference images or videos containing real human faces.

Three official workarounds:

1. **Faces from previous Seedance 2.0 outputs** — videos generated by Seedance 2.0 / 2.0 fast under your own account within the past 30 days are trusted as input assets and can carry faces forward.
2. **Preset digital characters** — pass an asset ID from BytePlus's digital character library (URI form, retrievable from the library).
3. **Authorized real-person assets** — separately licensed identity packs.

The three image-mode scenarios (first-frame, first-and-last-frame, multimodal reference-to-video) are **mutually exclusive** within a single task — you can't mix `first_frame` images with `reference_image` images.

## Three input modes (Seedance 2.0)

| Mode | Required `content` items | `role` |
|---|---|---|
| Text-to-video | 1 × `text` | n/a |
| Image-to-video (first frame) | 1 × `text` (optional) + 1 × `image_url` | `first_frame` (or blank) |
| Image-to-video (first + last frame) | 1 × `text` (optional) + 2 × `image_url` | `first_frame`, `last_frame` |
| Multimodal reference-to-video | text (optional) + 1–9 `image_url` + 0–3 `video_url` + 0–3 `audio_url` | `reference_image`, `reference_video`, `reference_audio` |

Allowed combinations for multimodal:
- text + image
- text + video
- text + image + audio
- text + image + video
- text + video + audio
- text + image + video + audio

Audio cannot be input alone — at least one reference image or video must accompany it.

## Verified input limits

### Images

| Field | Limit |
|---|---|
| Formats | jpeg, png, webp, bmp, tiff, gif (Seedance 1.5 pro also: heic, heif) |
| Width / height | 300 px – 6000 px each side |
| Per-file size | < 30 MB |
| Request body total | ≤ 64 MB (don't base64 large files) |
| Count — first frame | 1 |
| Count — first + last | 2 |
| Count — multimodal reference (S2.0) | 1–9 |
| Count — Seedance 1.0 lite reference | 1–4 |

### Videos (Seedance 2.0 only)

| Field | Limit |
|---|---|
| Formats | mp4, mov |
| Encoding (audio track) | AAC, MP3 |
| Resolution | 480p, 720p, 1080p |
| Duration per clip | 2–15 s |
| Total reference duration | ≤ 15 s across all clips |
| Reference video count | ≤ 3 |
| Per-file size | ≤ 50 MB |
| Frame rate | 24–60 fps |
| Aspect ratio range | width/height ∈ [0.4, 2.5] |
| Total pixel count | 409,600 ≤ w × h ≤ 2,086,876 |

### Audio (Seedance 2.0 only)

| Field | Limit |
|---|---|
| Formats | wav, mp3 |
| Duration per clip | 2–15 s |
| Total reference duration | ≤ 15 s across all clips |
| Reference audio count | ≤ 3 |
| Per-file size | ≤ 15 MB |
| Solo input | ❌ must accompany an image or video |

## Generation parameters

| Parameter | Type | Default | Range / Values |
|---|---|---|---|
| `resolution` | string | 720p (S2.0/2.0 fast/1.5 pro/1.0 lite), 1080p (S1.0 pro/pro-fast) | 480p, 720p, 1080p (S2.0 fast doesn't support 1080p) |
| `ratio` | string | adaptive (S2.0 / 1.5 pro), 16:9 / adaptive (others) | 16:9, 4:3, 1:1, 3:4, 9:16, 21:9, adaptive |
| `duration` | int (s) | 5 | S2.0: [4,15] or -1 (auto) · 1.5 pro: [4,12] or -1 · 1.0: [2,12] |
| `frames` | int | — | [29, 289] following `25 + 4n`. **Not supported on S2.0 / 1.5 pro.** |
| `seed` | int | -1 (random) | [-1, 2³²-1] |
| `generate_audio` | bool | true | S2.0 / 2.0 fast / 1.5 pro only |
| `watermark` | bool | false | — |
| `camera_fixed` | bool | false | Not supported on S2.0 |
| `return_last_frame` | bool | false | PNG, no watermark, same dims as the video — useful for chaining |
| `draft` | bool | false | S1.5 pro only — 480p preview |
| `service_tier` | string | default | `default` (online) · `flex` (offline, 50% price; **not supported on S2.0**) |
| `execution_expires_after` | int (s) | 172800 (48h) | [3600, 259200] |
| `callback_url` | string | — | Webhook for task status changes (3 retries on 5s timeout) |
| `safety_identifier` | string | — | Stable hashed user ID, ASCII, ≤64 chars |

## Languages and prompt length

- **All models**: English prompts.
- **Seedance 2.0 / 2.0 fast (additionally)**: Japanese, Indonesian, Spanish, Portuguese.
- **Length cap**: keep English prompts ≤ 1000 words — longer prompts cause the model to lose focus and drop details.
