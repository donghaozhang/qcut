# 封面对标第三轮：Iceland 侧转文字与画布空间

日期：2026-09-06。分支：`codex/cover-design`，沿用 PR #463。

## 本轮变化

- Iceland 模板不再被统一的竖排检查拒绝。剪映实机中，左侧 `TRAVEL WITH FRIENDS` 是整行英文顺时针侧转；QCut 将已验证的纯 ASCII 文字排版映射成现有可编辑文字图层的 90 度旋转，并叠加源片段旋转。
- 保留原文、尾部换行、三份真实缓存字体、颜色、相对位置和图层顺序。没有把文字烘焙成贴图，也没有把中文拆成逐字换行。
- 宽高与旋转移到“尺寸与旋转”图标弹层，支持滑杆、数值、键盘打开、Escape 关闭，以及忙碌和切换图层后的关闭。关闭弹层不关闭封面编辑器。
- 桌面工具栏和胶片条缩紧。1136×676 窗口、选中 Iceland 英文时，画布高度由本轮修改前的 169px 增至 280px，约增加 66%。保留十帧胶片条和全部编辑入口。

## 边界与后续

- “已验证”严格指文字布局渲染、保存、重开，不是剪映完整模板或逐像素一致。
- Iceland 仍缺 `filter/77a842c891a712e7569d6799d631bf46`（小镇）；保留当前背景，不以同名滤镜冒充。全样本仍有五个旧背景滤镜缺口。
- 同源截图仍能看到字号、字距和字形度量差异，尤其英文侧栏；本轮修复方向和可编辑套用，不宣称排版完全一致。
- 只支持 `typesetting=1` 的纯可打印 ASCII 与换行，且不能带原生花字效果。中文、混排、组合字符、emoji 和花字竖排继续显式拒绝。用户后续改为中文得到普通旋转文字，不是原生中文竖排引擎。
- 本轮能正常进入剪映封面子窗口，旧文档中的窗口访问阻塞不再复现；但没有逐分类翻页采集全目录，八个样本不能代表完整数量。
