# 封面对照增量：真实缩略图、竖屏布局与原生花字颜色

日期：2026-09-06。分支：`codex/cover-design`。PR：[#463](https://github.com/Quriosity-agent/qcut/pull/463)。

## 本轮变化

- 私有模板目录在桌面和窄桌面保持双列，卡片使用自有缓存里的真实预览图；缩短标题区域，压缩标题栏和文字输入框，模板详情独立滚动。
- 资源已就绪且运行时可用的卡片单击即套用文字布局；未就绪卡片只显示诊断，不制造成功状态。生成期间禁用卡片。
- 胶片条默认展开，按项目 FPS 在首帧到末帧之间抽取最多十个不同帧号，保留加载占位；媒体未恢复时不使用失效缩略图。
- 实机发现并修复刷新后过早打开封面的时长快照问题：时长现在跟随时间线恢复更新，自动展开不覆盖用户主动收起的选择。
- 竖屏套用保留原生归一化位置 `x=(1+transform.x)/2`、`y=(1-transform.y)/2`；字号按画布短边缩放，不再把位置一起缩进横屏画布的内接矩形。
- 原生模板的 `use_effect_default_color` 从定义解析、模型持久化一直传到已有花字运行时。只有显式 `false` 才发送文字填色；缺省行为保持效果包默认颜色。
- TextStyle/InfoSticker 支持工具栏改色；ScriptInfoSticker 不支持此主文字填色覆盖，UI 禁用且运行时明确拒绝。切换预设或移除花字清除旧颜色模式。

## 原生颜色链路

S23 模板主标题指定 `#047bff`，副标题指定 `#ffbf17`，同时设置 `use_effect_default_color:false`。此前解析器丢掉该字段，原生桥又固定开启默认配色，导致资源虽齐全，实际颜色仍不同。

现在渲染请求的 `textColor` 进入缓存键；桥接环境显式设置或清空 `JY_TEXT_COLOR`，避免继承其他进程的值。原生桥调用本机已验证的 `TextStickerFilter::set_text_color(const std::string&)`，关闭默认效果色。仅接受六位十六进制颜色，拒绝脚本组件和外部生成的 segment payload，避免静默忽略参数。

真实字体、效果包、运行库仍是用户私有本机依赖，不作为公开 QCut 素材分发。缓存预览图只用于挑选模板，最终图片来自实际文字渲染，不把目录缩略图铺到用户封面上。

## 尚未对齐

1. 没有增加目录数量：当前 UI 仍显示八套已缓存样本，不是剪映在线全量；发现、缓存、可套用和已验证不能合并统计。
2. 缺失背景滤镜和完整 `cover_draft` 背景合成仍未解决；这一轮实现的是可编辑文字布局和效果色。
3. 原生描边、字形、字间距仍有肉眼差异，尤其 S23 的红色字形；不宣称像素级一致。
4. 实测源模板为 1280×720 定义；短边缩放不能当成所有模板比例、竖排和多脚本模板都已验证。Iceland 竖排限制保留。
5. 十点胶片条是抽样而非完整时间线缓存，复杂时间线取帧可能较慢。跨机器字体/运行库迁移、可搬运封面资源和完整工程导出不在此次验收内。
