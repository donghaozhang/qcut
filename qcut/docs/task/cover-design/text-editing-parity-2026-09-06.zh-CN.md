# 封面文字编辑：缩小剪映交互差距

日期：2026-09-06。分支：`codex/cover-design`。现有 PR：[#463](https://github.com/Quriosity-agent/qcut/pull/463)。

本记录是 [前一轮 UI 对照](./ui-comparison-2026-09-06.zh-CN.md) 的增量，不把历史截图或缓存完整性当成当前原生渲染证据。

这是第一阶段的历史记录。后续已复用现有花字和字体实验室接入原生渲染，见 [原生花字与字体接入验证](./native-word-art-2026-09-06.zh-CN.md)。下面的测试数量与静态近似限制仅描述第一阶段。

## 本轮补齐

| 项目 | 之前 | 现在 |
| --- | --- | --- |
| 描边 | 开关、固定黑色和粗细 | 颜色、粗细、不透明度 |
| 阴影 | 开关、固定参数 | 颜色、不透明度、模糊、水平/垂直偏移 |
| 背景 | 开关、固定深色 | 颜色、不透明度、圆角、内边距 |
| 发光 | 无 | 独立启用、颜色、强度、范围 |
| 排版 | 固定字间距与行距 | 字间距、行距、垂直对齐 |
| 文字预设 | 封面未接入 | 复用现有 13 个文字预设，实际 Canvas 预览、搜索和应用 |
| 花字实验室 | 仅模板依赖映射 | 复用已有实验室目录、类别与 approximation 参数，显示静态近似样式 |
| 窄屏 | 新增样式区会被旧横排文本列表挤出 | 文本与样式共用纵向滚动区，参数弹窗限制在视口内 |

这些参数经过封面模型验证，保存进 `CoverDesignV1.layers[]` 中的文字层 `textStyle`，正式封面、预览和样式卡片继续复用时间线文字绘制器。旧设计没有 `textStyle` 时使用原默认效果；效果关闭后保留数值，重新启用可恢复。

应用样式保留文字内容、图层 ID、字体族、字号、位置、文本框与旋转。预设里的字体族不在本轮导入范围内；样式卡片是默认字体示例，不保证与用户当前字体逐像素相同。不存在原生包路径或临时运行时引用写入设计的情况。

## 验证

- 191 项测试、22 个文件通过：封面模型、样式转换、文字绘制、参数面板、样式库，以及既有保存/复制/重开/指定帧/共享弹窗/缓存依赖回归。
- Web `tsc --noEmit`、本轮源文件 Biome、`git diff --check` 通过。
- 真实浏览器：在既有测试项目选择“夏天的旅行”，应用“醒目黄字”，设置描边粗细 `10`、不透明度 `0.75`、字间距 `6`、行距 `1.8`；撤销后行距返回 `1.2`，重做后保存。
- 等待保存关闭，再完整刷新项目并重开：上述四个参数恢复，原有模板文字和手动文字保留。
- 实测 1440×900、默认 790×842、390×844；窄屏搜索“霓虹”后两张对应样式卡可见，工具栏换行，弹窗未越界。结束时恢复默认视口。

真实私有花字缓存另做只读转换校验：`~/Library/Application Support/QCut/PrivateAssets/JianyingText/Cache/artistEffect` 的 2,401 个候选包产生 2,394 条有效目录记录。其中 1,143 条具有 approximation，全部通过封面参数转换与验证；1,251 条没有静态近似，不能据此套用。

这些是原始本地目录记录数，不是去重后的 UI 可见数量，也不是 1,143 个效果已逐一通过视觉一致性测试。浏览器没有 Electron IPC，实验室入口显示桌面版可用提示；本轮没有把 mock 当成桌面端真实花字套用证据。原生模板卡片与静态文字样式入口仍是不同功能。

## 剩余差距

- 第一阶段没有连接 InfoSticker、复杂贴图花字和真实字体；这些能力已有实验室与运行时，并非需要重写引擎。后续接入情况见上面的原生花字文档。完整原生封面模板仍不能直接应用。
- 花字 approximation 只带入受支持的静态描边、阴影、发光等参数，不带动画、材质、图片或原生字体。非 flat-compatible 项明确显示“近似样式”。
- 系统字体仍为三类；没有新增剪映字体下载、气泡素材库、多选或画布缩放/旋转手柄。
- 剪映分类/模板缓存规模、连续胶片、复杂转场取帧、Electron 原生存储与跨机打包不是本轮修改范围。
