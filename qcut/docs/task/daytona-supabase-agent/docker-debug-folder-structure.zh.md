# Docker_debug 文件夹结构理解

## 总结

`docs/task/daytona-supabase-agent/Docker_debug/` 是一个本地调试和导出资料包，不是 QCut 应用代码的一部分。它主要保存了「GenAI 工作群」视频课程的审评意见导出文件，并把这些 Excel 审评表整理成 CSV 和一个可本地浏览的 HTML 页面。

这个目录继续被 git 忽略是合理的，因为它包含生成物、审评截图、Excel 导出、个人设备配置说明，以及带有本地路径的资料说明。

## 主要内容

| 路径 | 类型 | 作用 |
| --- | --- | --- |
| `审评意见汇总-合集/` | Excel 导出合集 | 包含 64 个 `.xlsx` 审评意见汇总文件，对应多集视频和多个版本。 |
| `审评意见图片/` | 抽取出的截图 | 包含 261 张 `.jpeg`，是从 Excel 内嵌媒体里抽出来的评论帧截图。 |
| `审评意见汇总.csv` | 生成的 CSV | 汇总后的审评数据，包含集数、视频、时间戳、评论者、意见、完成状态、主题、图片路径和源文件。 |
| `review-feedback-browser.html` | 生成的本地浏览器 | 一个独立 HTML 页面，内嵌审评数据，可按评论者、主题、集数、完成状态筛选。 |
| `build_review_site.py` | 生成脚本 | 解析审评 Excel，抽取内嵌截图，生成 CSV 和 HTML 浏览页。 |
| `analyze_excel.py` | 分析脚本 | 统计每个 Excel 的评论数、完成数、截图数和主要评论者。 |
| `inspect_excel.py` | 探查脚本 | 打印样例工作表内容，用于理解 Excel 导出的表格结构。 |
| `PERIPHERALS_SETUP.md` | 个人设备笔记 | 英文版 Mac 外设连接和排查说明。 |
| `外设连接说明.md` | 个人设备笔记 | 中文版 Mac 外设连接和排查说明。 |
| `FFAS-4.8-docs/FFAS-4.8-structure.md` | 原始素材目录说明 | 记录本地 `FFAS-4.8` 视频素材目录结构，以及缺失集数。 |

## 文件数量

当前本地目录共有 334 个文件：

| 后缀 | 数量 | 含义 |
| --- | ---: | --- |
| `.jpeg` | 261 | 从审评表里抽取出的评论帧截图。 |
| `.xlsx` | 64 | 审评意见汇总表。 |
| `.py` | 3 | 一次性的解析、分析、探查脚本。 |
| `.md` | 3 | 笔记和原始素材结构说明。 |
| `.html` | 1 | 生成的审评意见浏览页。 |
| `.csv` | 1 | 生成的审评意见汇总数据。 |
| `.DS_Store` | 1 | macOS 元数据文件。 |

目录大小约为 23 MB。

## 数据流

```text
审评 Excel 导出
  -> build_review_site.py
  -> 抽取 JPEG 截图
  -> 汇总 CSV
  -> 独立 HTML 审评浏览器
```

这些脚本默认从 `审评意见汇总-合集/` 读取 Excel。`build_review_site.py` 会读取 Excel 压缩包内部的图片资源，把图片和对应评论行匹配起来，复制到 `审评意见图片/`，再生成 `审评意见汇总.csv`，最后把审评记录嵌入 `review-feedback-browser.html`。

## 为什么应该继续忽略

这个目录不应该进入 git，因为它是本地资料和生成物集合，不是可复用的应用源码。里面包含生成截图、生成 CSV/HTML、导出的审评表、评论者和评论内容、个人硬件笔记，以及绝对本地路径。保留一份被 git 跟踪的结构说明更合适，也能避免把无关资料带进仓库。
