## 怎么用这份名单

1. **先加 LinkedIn，附一句你在 Hackathon 上做了什么**。别写长信，一句话说清楚你在建什么。
2. **标了 ⭐ 的三位优先联系**（如果你做的跟 AI/Video 有关）。
3. **Tier 1 的基金先不急**，除非你已经有 traction。先跟 Tier 2 的聊，他们决策更快。
4. **SOSV 有两个人到场（Mohan + Parikshit）**，说明他们对这个方向有兴趣，值得深入了解。
5. **Civilization Ventures 也来了两个人**，小基金来两个人 = 很认真。
