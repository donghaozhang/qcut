# 轨道类型对照：QCut vs 剪映（贴纸 / 滤镜 / 特效 / 调节 / 音频 / 文本）

日期：2026-08-18 · 姊妹篇：[README.md](README.md)（主轨/画中画/吸附/磁性）

剪映侧全部实机操作（草稿 `8月18日`，实验编号 J1-J5 见文末）；QCut 侧
规则带 file:line。

## 先说最大的差异：层级世界观

**剪映：浮层轨「后加者居上」，无类型分层。** 实测顺序：先加文本 → 再加
贴纸（落文本**上方**）→ 再加文本（落贴纸**上方**）→ 滤镜、特效、调节
依次落到当时的最顶。文本/贴纸/滤镜/特效/调节在主轨上方同一个浮层区里
纯按添加时序叠放，轨道整体不可拖拽重排（只能移动段）。音频恒在主轨
下方。

**QCut：类型分层 + 显式重排。** `TRACK_PRIORITY`：text 1 < captions 2 <
markdown 2.5 < remotion 3 < hyperframes 3.25 < sticker 4 < adjustment
4.5 < effect 4.75 < media 5 < audio 6（[track-utils.ts:12-23]）——
**默认文本压在贴纸上面**，与剪映相反（剪映谁后加谁在上）。这是默认
落位而非不变量：现代项目带显式 `order` 字段，`moveTrack` 允许用户自由
重排任何轨道、覆盖类型序（[track-utils.ts:88-112]）——剪映做不到的
能力。

含义：从剪映导入的草稿在 QCut 里重排序后，浮层遮挡关系可能与剪映原片
不同（导入层用数组序做 `order` 保真，但用户一重排就进入 QCut 世界观）。

## 逐类型对照

### 1. 贴纸

| | 剪映（实测 J1） | QCut |
|---|---|---|
| 落轨 | 自动建贴纸轨，位置=当时最顶 | `ensureStickerTrack`：复用第一条贴纸轨，没有则 `insertTrackAt("sticker", 0)`（[timeline-sticker-integration.ts:131-212]） |
| 起点 | 播放头 | 播放头（面板点击）/拖放位置 |
| 默认时长 | ≈5s | 5s（各调用点硬编码） |
| 重叠处理 | 未对测 | 复制贴纸若重叠则再叠新贴纸轨 |
| 特例 | **脚本贴纸（数据图表）作为主轨片段插入并右推**——不是浮层！ | 无对应概念；剪映 ScriptInfoSticker 在互导里本就 opaque |

结论：**基本同构**。脚本贴纸的主轨插入行为是唯一意外，互导层已把
ScriptInfoSticker 挡在 opaque 级，无风险。

### 2. 文本 / 字幕

| | 剪映（实测 J1b/E7） | QCut |
|---|---|---|
| 落轨 | 每次建新轨于当时最顶（不复用空文本轨） | 每次 `insertTrackAt("text", 0)` 建新轨于最顶（[timeline-add-ops.ts:121]）——同样不复用 |
| 默认时长 | **3s** | **5s**（`DEFAULT_TEXT_DURATION`） |
| 字幕 | 识别字幕入字幕轨；draft 里 material type `"subtitle"` 与普通 `"text"` 区分 | 独立 `captions` 轨类型（priority 2）；互导把两者都映射为剪映 text 轨（[text-mapping.ts:498,531]） |

结论：建轨策略一致，**默认时长 3s vs 5s** 是仅有的行为差。

### 3. 滤镜

| | 剪映（实测 J2） | QCut |
|---|---|---|
| 应用模型 | + 号**永远建独立滤镜轨段**（即使有片段选中），段带「强度」参数，作用于时间范围内其下所有层；拖到具体片段上才挂片段 | **没有滤镜轨类型**。滤镜/LUT 写进目标的 colorSettings：有选中（媒体片段或调节层）写选中者，无选中自动 `createAdjustment` 建调节层（[use-adjustment-lut.ts:142-158,160-210]） |
| 默认时长 | ≈3s 段 | 调节层默认 max(5s, 播放头→项目尾)（[adjustment-layer.ts:45-49]） |
| 参数 | 强度 0-100 | LUT intensity + 完整 color settings |

结论：**参数能力部分重叠，作用域与时间行为不同**。剪映滤镜段作用于
其下所有层、默认 ≈3s 独立时间段；QCut 写进单个片段或调节层——调节层
只调媒体不碰浮层、默认从播放头到项目尾。交互模型亦不同：剪映「滤镜是
个可拖拽的段」；QCut「滤镜是片段/调节层的属性」。剪映的滤镜段在
draft 里是 filter 轨 + extra_material_refs LUT——互导按 opaque 保留。

### 4. 特效

| | 剪映（实测 J3） | QCut |
|---|---|---|
| 应用模型 | **特效轨段**（默认 ≈3s，起点=播放头），作用于其下所有层（实测雨滴打在贴纸上）；每特效带独立参数集（雨滴：大小/纹理/模糊/速度/噪点/柔和/范围） | **特效挂片段**：`effectsStore.applyEffect(elementId, preset)`，`effect` TrackType 在模型里存在但**没有任何代码创建 effect 轨**（[effects.tsx:213-221]；track-model 审读确认零调用点）；「特效轨道」只是 UI lane 开关 |
| 参数 | 每段可调 | `adjustParameters`（特效实验室已镜像剪映参数 schema） |

结论：**真差距**。剪映的区间特效段（作用一段时间内所有层）QCut 没有
对应物——挂片段的特效只作用于那个片段。要对齐需要激活 effect 轨类型
并让渲染管线支持「特效段作用其下」。这也是特效实验室里的剪映特效目前
只能逐片段应用的原因。

### 5. 调节

| | 剪映（实测 J4） | QCut |
|---|---|---|
| 应用模型 | 调节轨段，面板：基础/HSL/曲线/色轮/蒙版 + 智能调色/色彩克隆/色彩校正/LUT 槽 | `adjustment` 轨（priority 4.5），`addAdjustmentLayer` 插在最顶 media 轨上方——刻意让它调色所有媒体但不碰文本/贴纸浮层（[adjustment-layer.ts:16-44]） |
| 默认时长 | ≈3s | max(5s, 播放头→项目尾) |
| 作用域 | 其下所有层（含贴纸文本？未单测） | 其下的 media 层 |

结论：**同构度最高的一对**。差异在默认时长与插入位置哲学（剪映插最顶
=也调浮层；QCut 刻意插在浮层之下=只调媒体）。

### 6. 音频

| | 剪映（实测 J5） | QCut |
|---|---|---|
| 落轨 | 主轨下方音频轨，起点=播放头，允许 gap | 同：audio 轨默认在底部（moveTrack 可重排）（priority 6，新音频轨 `addTrack("audio")` 追加底部），`addMediaAtTime` 起点=播放头，找空 lane 或叠新轨（[timeline-add-ops.ts:76-116]） |
| 片段音频面板 | dB 音量、淡入/淡出时长、响度统一、降噪、人声美化、声音分离、变调、立体声平衡、声道配置；tab：换音色/声音效果/变速/改词翻唱 | `volumeDb`、`fadeIn/fadeOut`（[audio-basic-settings.tsx]、[timeline.ts:717-718]）、playbackRate/preservePitch、EQ/压缩器/声像（导出层枚举过） |
| 轨级能力 | （未对测轨级） | 轨级 audio bus（`TimelineTrackAudioSettings`）+ 轨内 crossfades（`audioCrossfades`）——剪映无轨级总线概念 |
| 视频分离音频 | 「分离音频」（未实测） | `separateAudio`：分离副本落空闲 audio 轨或叠新轨，groupId 链接、原片段内嵌音频静音（[timeline-element-ops.ts:362-464]） |

结论：**基本同构**，两边各有对方没有的高级件（剪映：换音色/改词翻唱
等 AI 件；QCut：轨级 bus 与 crossfade）。互导注意：QCut 的 fade/EQ/
声像导出剪映会被列为阻断错误（fades 在剪映是 audio_fades 伴生素材，
QCut 导出线尚未映射）。

## 汇总

| 轨型 | 同构度（成文时） | 关键差 | 2026-08-18 后状态 |
|---|---|---|---|
| 贴纸 | 高 | 脚本贴纸插主轨（互导已挡 opaque） | 不复刻，维持 |
| 文本/字幕 | 高 | 默认 3s vs 5s | T7 口味项，未动 |
| 滤镜 | 中 | 段实体 vs 属性；QCut 无滤镜轨 | 有意保留（表达力等价物在） |
| 特效 | ~~低~~ | ~~剪映区间特效段作用其下所有层，QCut 只有挂片段~~ | **T5 阶段1 已落地**：区间段作用媒体层；浮层覆盖与本机特效留阶段2 |
| 调节 | 最高 | 插入位置哲学（调浮层 vs 只调媒体） | byArrival 开时调节层也落最顶（连浮层一起调） |
| 音频 | 高 | 各有独占高级件；fade 不能导出到剪映 | 维持 |
| ~~层级~~ | ~~低~~ | ~~后加者居上 vs 类型分层~~ | **T6 已落地**：`overlayStacking` per-project 开关，默认 byType |

对齐优先级建议（复盘：三条全部按建议执行）：① effect 轨段 → T5 阶段1
✅；② 层级开关而非改世界观 → T6 ✅（正是「慎动 TRACK_PRIORITY」的
落法）；③ 文本 3s 留作产品口味 → T7 未动 ✅。
