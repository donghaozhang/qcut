# Framing Dimension

## Options

### wide

- Show environment and context first
- Favor establishing geography
- Keep subjects readable but not dominant

### medium

- Balance subject and environment
- Good default for explanatory beats
- Preserve body language and nearby context

### close

- Focus on expression, gesture, or key object interaction
- Reduce environmental distraction
- Favor emotional clarity

### macro

- Extreme detail shot
- Texture, hands, tools, screens, or small objects
- Use only when detail is story-relevant

### overhead

- Top-down planning view
- Strong for process, layout, or object relationships
- Keep arrangement clean and intentional
