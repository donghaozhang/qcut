# Promo 成片迭代经验(2026-08-01 起累计)

对 `--promo` 工作流产出的宣传片做多轮优化时踩过的坑与固定打法。
每轮优化都必须:改一处 → 重渲染 → **逐帧对比验收** → 记录得失到本文档。

## 逐帧 QA 是唯一可信的验收方式

- 原始录屏必先做接触表再用:`ffmpeg -vf "fps=1/2,crop=<画布区>,tile=7x4"`。
  录屏里有大段"空画布"(面板点击、出场动画播完、占位框),连续
  `startFrom` 播放会把这些废段带进成片,观众读作 bug。
- 证明"文字在动"要用**姿态对**:取相隔 0.3–0.5s 的两帧并排
  (`hstack`),字符基线高度不同才算动;单帧或 2s 间隔的接触表看不出
  wave 循环。
- 成片验收固定抽:问题时间点(用户报过的秒数)、每个拼接缝前后帧、
  Outro 相隔 1s 的两帧。参数校验(分辨率/帧率/时长)不能替代目检——
  出现过"参数全对、画面全废"的素材。

## 源录屏的剪法:keep-window 拼接

- 在 Remotion 里把 `<Video startFrom>` 换成 per-segment 列表
  `{fromSeconds, toSeconds, rate?, video?}[]`,只保留"画布上有字"的窗
  口;每段可独立倍速、独立源文件(补录素材混入同一节拍序列)。
- **总帧数保持不变**:配音/BGM 与画面的对位靠总长锁定,demo 段剪短后
  把差值全部给 Outro,不要动前面场景的起点。
- 中文操作用原速(1×)最自然,英文 1.75× 起步;2× 会让打字段发飘。

## 补录素材(tail take)的固定流程

1. 用 `editor:demo:run --plan` 新建**独立项目**录制,绝不动用户已开的
   项目;plan `timeline` 里可直接预烘焙
   `textAnimationPreset: {phase:"loop", presetId:"wave"}` 的文字元素,
   不需要虚拟鼠标逐字输入。
2. **plan 时间线的轨道数组是"先列者在上层"**:media 轨排第一会盖住
   文字轨(渲染层序 = UI 自上而下)。文字/overlay 轨必须排在 media 轨
   前面,否则画布上看不到字(踩过:录了两条全是背景的废片)。
3. 循环动画只在**播放中**运动:actions 必须
   `click timeline.play` + `sleep <时长>`,暂停帧是静止 pose。
4. 原生 2K:先把窗口挪回主显示器(可能开在 1080p 副屏),再进系统全屏
   (`AXFullScreen`);非全屏窗口捕获会报 2504×1440 之类的怪尺寸
   (窗口 chrome 内缩),全屏捕获才是真 2560×1440。
5. macOS 屏幕录制权限误报(TCC 数据库已授权但状态查询报 denied):
   用代码自带的 `QCUT_SKIP_PERMISSION_CHECK=1` 重启应用,这个环境变量
   就是为该场景设计的逃生门。
6. 录制质量校验 `minimumWidth` 只做拒收不做缩放;素材差 ≤3% 时放宽
   校验比追平更划算(合成端 2504→2560 的 1.02× 放大不可见)。

## 第二轮追加(动画面板出镜 + zoom region 污染)

- **每条录制之间必须重启 QCut**:一次录制结束会自动生成 1.5× 鼠标
  聚焦 zoom region 并留在全局 store,下一条录制的画面内容被缩放偏移
  而选择框不动——表现为"文字飘出选框"。开发构建没有暴露清空入口,
  重启是唯一可靠解法(每次重启后重新挪主屏 + 全屏)。
- 让功能面板出镜替代穿帮的"屏幕录制"设置面板:录制动作先
  `click x/y`(画布中心,选中文字)→ `click text.animation` →
  `click text.animation.loop`,循环预设网格会带着高亮的 wave 卡片
  入画,既是 UI 连续性也是功能展示。actions 数组支持裸坐标点击
  (`{"action":"click","x":...,"y":...}`)。
- 拼接段起点要留 0.2–0.3s 余量:恰好切在文字出现的前一瞬会让首帧
  空画布/占位框漏进成片(EN E2 29.8→30.0、ZH Z5 39.0→39.3 各修过
  一次)。

## 第三、四轮追加(拼接缝音效 + 窗口收紧 + Outro 排版)

- 拼接硬切用低音量 `transition-snap.mp3`(volume ≈0.26)盖在每个内部
  缝上;在合成里由段列表**推导**缝帧位(`editorSeamFrames`),不要写
  死帧号——段一改缝就跟着走。
- 验证"某版比上一版多了音效"用**反相抵消法**:两版同窗口抽 wav,
  一路 `aeval=-val(0)|-val(1)` 反相后 amix,残差 mean_volume 非静音
  (≥−40dB)即差异存在;VO 压着的场景直接比 mean_volume 分不出来。
- 裁掉弱画面段后**必须回看新缝两侧各 ±0.5s**:第一刀往往切不干净
  (E1 裁 14–15.5 后,两侧仍各剩 ~0.7s 空画布,第二刀 12.4/16.3 才
  收干净)。迭代预算里要给"同一处收两刀"留空间。
- Outro 文字动画参数(2560×1440 下的实测手感):标语 54px、逐词
  wave 振幅 11px、周期 ~0.9s、错峰 0.85rad;高亮词加呼吸辉光
  (textShadow 亮度用 sin(frame/14) 摆动)。44px/9px 在 2K 上偏弱。

## 已知残留(后续候选)

- EN 82px 文字在默认文本框内换行为两行;打字输入会触发 grow 模式而
  预置元素不会。作为收尾定格两行反而有分量,暂不改。
- tail take 属性面板下半部仍露出一点"屏幕录制"分组(动画面板占据
  上半屏后基本不可见),完美主义者可在录制前把面板滚动到顶。
