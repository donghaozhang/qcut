# Shot Analysis Framework

Use this framework to turn source content into a shot plan.

## Core Questions

- What is the main subject of the scene?
- What changes emotionally from start to finish?
- What visual beats are mandatory?
- What should be shown wide vs close?
- Where are the transitions, reveals, or payoff moments?

## Shot Priorities

### Must Cover

- opening context
- key action or claim
- emotional change
- payoff or closing image

### Optional Coverage

- reaction shots
- detail inserts
- transitional cutaways
- environment texture shots

## Shot Flow

1. Opening context
2. Introduce subject
3. Advance action or explanation
4. Highlight a specific detail
5. Land a closing beat
